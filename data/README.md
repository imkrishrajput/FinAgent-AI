# Data

This project does not include real financial datasets or personal bank statements to protect user privacy.

## Supported Input

The application supports:

- PDF bank statements
- CSV transaction files

## Sample Data

You can test the application using:

- Your own PDF bank statements
- Your own CSV transaction files
- Sample transaction datasets from Kaggle

Example dataset sources:

- https://www.kaggle.com/datasets
- Google Pay transaction exports
- PhonePe transaction exports
- Paytm transaction exports

> Note: Large datasets and confidential financial documents are intentionally excluded from this repository.
